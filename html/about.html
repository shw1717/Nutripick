서비스 소개

기획 의도

NutriPick은 건강 고민을 단순히 선택하는 방식이 아니라, 생활패턴과 식습관 데이터를 통해 사용자의 고민을 카테고리화하고 영양제를 추천하는 프론트엔드 웹 프로젝트입니다.

추천 기준

1순위 생활패턴과 2순위 식습관만 사용합니다. 수면 부족, 실내생활, 화면 사용, 운동 부족, 생선·채소·유제품 섭취 부족, 아침 결식, 배달음식 빈도를 기준으로 추천 카테고리를 계산합니다.

사용 기술

HTML, CSS, JavaScript, JSON 객체배열, map(), filter(), sort(), localStorage

AI 서비스 확장 방향

현재는 선택형 규칙 기반 추천이지만, 추후 AI API를 연결하면 사용자의 자연어 입력을 생활패턴·식습관 키워드로 분류하고 추천 이유를 자동 생성하는 서비스로 확장할 수 있습니다.

주의: 본 서비스는 의료 진단이나 치료 목적이 아니라 학습용 추천 서비스입니다.
